The boring stack that runs my scrapers

I spend most of my days writing scrapers — small tools that pull public data into clean, structured files. The tools themselves are the fun part. The stack around them is deliberately boring.

Here's the whole thing: one VPS, a scheduler, and plain files.

The machine

One Linux VPS. Not a cluster, not Kubernetes — a single box with enough RAM to hold a browser tab or two. Everything runs on it: the scrapers, the scheduler, the tiny web servers.

Why one box? Because my scrapers are small. A scraper that runs once a day and pulls a few thousand records does not need a fleet. A fleet is a problem you get to have when your tool is being used by thousands of people — and I'm not there yet. When I am, I'll rent a second box.

The scheduler

A cron file. That's it. Five lines that say "run this every morning at 6, that one every Sunday."

Cron gets mocked for being ancient, and it deserves the respect: it has never once crashed, never needed a database migration, and every sysadmin on earth already knows how to read it.

The output

Plain files. JSON, mostly, sometimes CSV. Written to disk, synced to a public repo, served as static pages.

No database. No ORM. When a tool's whole job is "fetch and reshape," the database is a file. Static hosting is free, fast, and impossible to take down by accident.

What this buys me

  • Cheap to run — the whole thing costs less than a coffee subscription
  • Boring to debug — when something breaks at 2am, the logs are files, the state is files, and I can read them in any editor
  • Easy to hand off — every tool is one directory, one README, one command to run

What I'm not saying

I'm not saying this is the right stack for your project. If you're building a product with users, concurrent jobs, and real state — go rent the fleet, you'll need it.

I'm saying: for a solo developer shipping small data tools, the most expensive thing you can do is reach for the enterprise stack before the problem asks for it. Boring code is never debugged at 2am.
